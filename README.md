## 🚀 Featured Projects

### 1. TicketAI --- Customer Support Ticket Classification & Resolution Platform

An AI-powered support ticket platform designed to classify incoming
customer messages and support ticket resolution.

-   Uses a TF-IDF feature extraction pipeline with a LinearSVC-based
    classifier for ticket categorization.
-   Covers five ticket categories: Billing, Complaint, General Inquiry,
    Returns, and Technical Support.
-   Includes an LLM and RAG-based workflow to assist with ticket
    resolution.
-   Uses PostgreSQL through NeonDB for persistent storage.
-   Supports administrator-led ticket handling alongside AI-assisted
    resolution.

**Core technologies:** Python, Machine Learning, TF-IDF, LinearSVC, LLM,
RAG, PostgreSQL, NeonDB.
